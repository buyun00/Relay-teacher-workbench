# 课堂连接 0.1.0

- 标题栏下方常驻更新提示贯穿对话和录音页面：发现新版自动下载并显示进度，下载完成点击“重启并更新”，失败直接重试，无须打开设置。启动后自动检查，每30分钟复查；回到窗口、电脑唤醒或网络恢复时补查，网络失败5分钟后自动重试。

- 修复打开生成附件时偶发的主进程 JavaScript 报错；附件和对话连接改用 Electron 网络接口，完整副本继续复用，下载中断后可重试。

- 助手生成的成品直接显示在原回复的附件区，支持预览、保存、断线恢复和历史下载；多个文件和任意格式均适用。成品交付失败时保留已发送部分，明确提示尚未完整交付。

- React 浏览器预览与 Electron 桌面端共用界面。
- 界面收拢为左侧任务、右侧对话区和一个录音上传页；连接与更新设置使用折叠弹窗。
- 本机任务与消息草稿持久保存；原对话支持流式模型回复、工具执行状态、附件和历史恢复。
- 手动多选音频，先复制再进入同一上传队列；取消、改名重复、部分文件失败均可处理，不绑定所选文件目录。
- 绑定 USB 录音目录，自动复制已完成的录音，保留设备原件。
- SQLite 本地队列、内容去重、断线续传、持久化回执与处理状态查询。
- 接收端自动复用既有 ASR 与教师插件，保存课堂复盘和15分钟补充备课；客户端显示处理阶段并提供查看结果。
- 系统托盘、可选登录启动、Windows 加密连接凭据。
- GitHub Releases 自动检查业务更新，仅下载变化的代码和资源；下次启动自动启用，也可直接重启启用，无须运行安装程序。
- 同仓库 GitHub Actions 自动生成版本、测试和发布更新；无须额外发布 Token。
- 更新下载持续两分钟无进展时取消并提示重试，保留录音传输状态。
- 本地开发单独生成 Local 安装包；本地版本和输出目录独立，关闭 GitHub 自动更新，正式 CI 包继续自动发布和更新。
- 界面、preload 与后台服务作为同一完整版本切换；启动失败自动回退，保留录音队列、草稿与设置。稳定依赖资源分包，普通修改不重复下载 Electron 或未变的字体和依赖。

设备按文件存储读取；接收端启用自动处理后跟进录音流程，课次和学生身份未知时保留未知。对话与成品交付复用 Hermes 原生链路，保留原会话身份和持久化历史。
